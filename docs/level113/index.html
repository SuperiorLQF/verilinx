LEVEL 113

把颜色，归还给沙子。

拖动彩色容器，让容器的上边缘紧贴上方同色色仓的底边。只有贴住时才能接沙，隔着空格不会漏沙或自动向下落沙。填满后容器会消失，腾出新的空间。

容器不能穿过彼此或白色边框。标有 ↕ 的大方块只能上下移动。初始左仓装有蓝色和绿色混合沙，右仓装有粉色沙。混合仓内的两种现有颜色都可接取；上方管道是后续补充，不能提前接取。未贴住同色容器时，出沙口保持关闭；移开容器就停止填充。

拖动，或点选容器后点相邻空格。电脑也可用方向键。可以随时撤回、查看提示或加时。
