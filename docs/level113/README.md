# 彩沙谜局 · 关卡 113

独立的单关卡静态游戏，根据用户提供截图重绘布局、色彩与容器形状。截图无法确定原游戏的完整规则，因此这是采用以下明确规则的可玩复刻，并非原游戏程序或原版关卡数据。

- 6 × 9 不规则棋盘、15 个容器，包括两块互补 L 形容器和仅可竖移的大方块。
- 两个色仓分别覆盖棋盘第 2–3 列和第 4–5 列。只有容器实际格子在第 1 行、上边缘直接贴住对应同色色仓底边时才会接沙。隔空不出沙，不向下寻找容器；L 形缺口不算接触。移开时暂停填充，保留已接到的沙，不消耗队列；重新贴住同色色仓后继续。填满后容器消失，并消耗对应色仓一份颜色。
- 初始左仓为浅蓝色与绿色混合沙，右仓为粉色沙。混合仓内现有的任一颜色都能接取，填满时扣除对应颜色的一份；当前这一段颜色耗尽后才从管道补入新的颜色，不能填完一个容器就把剩余蓝绿沙全部换掉。管道颜色与仓内现有颜色分开显示，不允许提前消耗尚未进入仓内的颜色。左上两块 L 形容器属于浅蓝色（cyan）；四个侧边蓝色容器属于深蓝色（blue）。两者为独立颜色，不能相互接取。
- 每次沿单一轴滑动整数格。检查整个滑动路径，不能跨过其他容器或棋盘缺口。
- 拖动支持 Pointer Events、触屏 pointer capture 和 pointercancel；也可点选后点空格，或使用方向键。
- 180 秒倒计时、无限撤回移动、加时、重开、开关音效、暂停式玩法说明、胜利/超时界面。
- 提示在当前布局上用有界广度搜索寻找能让下一个容器消除的移动。7000 状态内无结果时明确建议撤回，不声称找到了完整解。
- 动画使用 Canvas 2D；不依赖网络资源、库、登录、后端或安装。系统开启减少动态效果时取消喷溅粒子。

## 本地运行与回归

```sh
python -m http.server 3080 --directory docs
# http://127.0.0.1:3080/level113/
node docs/level113/core.test.mjs
```

`core.mjs` 负责几何与规则；`game.mjs` 负责交互、动画及界面；不修改 Verilinx 后端或 Linux 发行包。通过现有 main / docs 的 GitHub Pages 发布。

## 可解性

核心回归同时验证：初始左浅蓝绿/右粉、浅蓝和深蓝互不混接、混合仓可选取现有任一颜色、扣除对应色、不能提前取管道供沙、隔空不接沙、移开暂停及完整通关。供沙仍采用有限容器份数的简化模型；原截图无法确定管道的完整后续色序和精确沙粒体积，后续补给色序仅用于确保该复刻关卡可玩，不宣称还原原游戏隐藏数据。

一条已验证的 20 次滑动路线（每个接沙动作后等容器消失）：

1. 初始浅蓝色 `c1` 贴住左仓，自动填满；右侧紫色 `p1` 不会接粉沙。
2. `p1` 左移 3 格，先等待；`c2` 上移 1 格接浅蓝沙后，左仓这一段浅蓝沙耗尽、补入紫沙，`p1` 才填满。
3. `m1` 上移 1 格；`p4` 上移 3 格；`g1` 上移 5 格；`p5` 上移 7 格。
4. `b1` 右移 1 格、上移 4 格；`b3` 右移 1 格、上移 7 格。
5. `b2` 左移 1 格、上移 4 格；`g2` 上移 5 格；`m2` 上移 7 格。
6. `p2` 右移 3 格、上移 1 格；`p3` 左移 1 格、上移 1 格；`b4` 左移 1 格、上移 7 格。

不保证最少步数。`shades-4` 资源版本用于避开旧缓存。
